# Cafe Nusantara ☕

Modern cafe landing page built with React + Tailwind + Framer Motion.

🌐 Live Demo: https://cafe-portfolio-ten.vercel.app/

## Features
- Responsive design
- Dark mode
- Animated UI
- Email contact form (EmailJS)
- Toast notifications

## Tech Stack
- React
- Tailwind CSS
- Framer Motion
- EmailJS
- Vercel
